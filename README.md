# 🧭 CareerCompass-AI

> **AI-powered personalized career discovery, psychological insights, and career roadmap platform.**

CareerCompass-AI helps students and professionals understand their **interests, personality, strengths, behavioral patterns, motivations, and career preferences** through an AI-powered assessment. Based on their responses, it generates personalized career recommendations and an actionable learning roadmap.

## ✨ Key Features

- 🧠 **Psychology-Based Career Analysis**
  - Interests and behavioral patterns
  - Strengths and work preferences
  - Motivation and career tendencies
  - Personality trait analysis

- 🎯 **Personalized Career Recommendations**
  - Suitable career streams
  - Recommended job roles
  - Match reasoning based on user responses
  - Career paths to reconsider

- 🗺️ **AI Career Roadmap**
  - Recommended career direction
  - Required technical & soft skills
  - Structured learning path
  - Immediate actionable steps
  - 90-day career action plan

- 🎯 **Goal-Based Guidance**
  - Define personal career goals
  - Connect goals with career direction

- 📊 **Personal Dashboard**
  - Personalized career information
  - Saved analysis and progress

- 🔐 **Firebase Authentication**
  - Secure user authentication
  - User-specific career data storage
